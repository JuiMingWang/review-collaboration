REVIEW COLLABORATION · R11 VISUAL GUIDE

From a question to an evidence-based decision

The host prepares a focused packet and delegates discussion to a native subagent and an external reviewer. Reasons, evidence, and conditions return to the host for an adoption decision.

Start with the overview, then open the setup, review, improvement, or program detail you need.

Host: the agent talking to you. Delegate: its native subagent. Reviewer: a different agent tool. Complete receipt is not proof of correctness; an ordinary review does not rewrite the skill.
