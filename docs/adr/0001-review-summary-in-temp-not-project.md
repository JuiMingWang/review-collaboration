# 審查摘要存放在系統暫存資料夾，不放進本專案

**Status**: accepted

審查協作中，產出者為審查者準備的**審查摘要**是一份過程性文件，用完即可丟棄。曾考慮放進本專案資料夾（方便回溯查閱），但參考了 `/handoff` skill（"Save to the temporary directory of the user's OS - not the current workspace"）與既有的 `codex-peer-review` 機制（暫存於 `/tmp/codex-review.XXXXXXXX`）兩個獨立先例，兩者都刻意避免把過程性產物留在專案裡，理由是討論可能進行多輪、會不斷產生新檔案，若留在專案內會逐漸污染專案結構。

因此決定：審查摘要一律存放於系統暫存資料夾，討論結束後即可刪除，不影響專案。真正需要保留的，是討論產生的**重要結論**——這類結論改用 ADR 的形式（例如本文件）寫進本專案的 `docs/adr/`，永久留存、可追溯。也就是說，過程性產物（審查摘要）與永久性紀錄（ADR）是刻意分開處理的兩件事，不是遺漏。

## Considered Options

- **放進本專案資料夾**：方便隨時翻閱歷史摘要，但多輪討論會累積大量一次性檔案，污染專案結構。
- **放系統暫存資料夾（採用）**：討論結束即可丟棄，不污染專案；重要結論另外用 ADR 保留，不會因此喪失可追溯性。
